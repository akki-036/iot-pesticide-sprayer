# IoT-Based Pesticide Sprayer Control Platform

An IoT-based pesticide spraying prototype developed using ESP32, relay module, and Arduino IDE. The system enables wireless activation of the spraying mechanism using Bluetooth communication.

## Features

- Wireless spray activation using Bluetooth
- ESP32-based control system
- Relay-controlled pump activation
- Automated pesticide spraying prototype

## Tech Stack

- ESP32
- Arduino IDE
- Relay Module
- Bluetooth

## Project Overview

The project uses Bluetooth communication to send signals to the ESP32 module. The ESP32 communicates with the relay module to control the pump and activate the spraying mechanism remotely.
